# Прошлые версии

Здесь лежит то, что уже не участвует в сборке, но выбрасывать жалко.

## `tk-версия/`

Интерфейс до переписывания на SwiftUI (август 2026). Был нарисован
примитивами на Tk Canvas по координатам макета, из-за чего не давал ни теней,
ни скруглений, ни нормальной типографики. Вместе с ним лежат его тесты и
скрипты сборки той поры.

**Не запускать.** `setup.command` когда-то заканчивался запуском
`meeting_transcriber_gui_v25_10.py`, и на чистой машине установка падала
после получаса ожидания — файла в сборке давно нет.

## `макеты/`

Снимки экранов и макет из шести экранов, по которым сверялся интерфейс до
появления веб-прототипа.
