# Славатор

Расшифровка рабочих встреч на macOS. Всё считается на самом компьютере:
ни записи, ни стенограммы никуда не отправляются.

Что умеет:

- расшифровывает записи встреч и разделяет речь по голосам;
- узнаёт людей по голосу и предлагает имя, вычитанное из разговора;
- пишет живой звонок: собеседников со звука компьютера, вас с микрофона;
- диктует в любое текстовое поле по удержанию правого <kbd>⌥</kbd>;
- собирает резюме, решения и поручения — по кнопке, когда нужно.

## Как устроено

Две части, связанные через запуск подпроцесса и построчный обмен по stdout.

| Каталог | Что там |
|---|---|
| `app/` | Интерфейс на SwiftUI. Собирается `swiftc` из Command Line Tools, Xcode не нужен |
| `core/` | Обработка на Python: распознавание, разделение голосов, документы |
| `packaging/` | Сборка бандла, образа и установщик |
| `docs/` | План развития |
| `legacy/` | Прошлая версия интерфейса на Tk. В сборке не участвует |

Ядро печатает в stdout человеческие строки и машинные `@@PROGRESS@@`;
приложение читает их и рисует ход работы. Диктовка общается с отдельным
постоянным процессом (`core/dictation_worker.py`) построчным JSON в обе
стороны — модель держится в памяти, иначе на каждую фразу уходили бы секунды
на её загрузку.

### Стек

- **faster-whisper** (CTranslate2, без torch) — распознавание речи
- **sherpa-onnx** — разделение голосов, отпечатки голоса, детектор речи
- **Ollama + qwen3:8b** — резюме, определение имён, обработка надиктованного
- **SwiftUI + AppKit** — интерфейс

Ни аккаунтов, ни токенов: все модели открытые.

## Сборка

```bash
packaging/build_app.sh          # собрать Славатор.app
packaging/make_dmg.sh           # лёгкий образ (~2 МБ)
packaging/make_dmg.sh --full    # полный (~5 ГБ): Ollama и модель внутри
```

Требуется macOS 14.2 и новее на Apple Silicon. Command Line Tools обязательны,
полный Xcode — нет.

### Проверка после каждой сборки

Две вещи ломались молча и стоили дня работы, поэтому проверяются всегда:

```bash
otool -L packaging/dist/Славатор.app/Contents/MacOS/slavator | grep -c SwiftUICore   # 0
codesign --verify packaging/dist/Славатор.app                                        # valid
```

`SwiftUICore` — фреймворк из macOS 15. Если линковщик его пропишет,
приложение не запустится на macOS 14 вовсе: падение при старте, без окна.
Тянут его `.fixedSize()`, свои раскладки на протоколе `Layout` и `.tag()`
в `Picker` — эти три вещи в коде не использовать.

Подпись ломается, если Python успевает записать `__pycache__` внутрь бандла.
Вместе с подписью слетают выданные разрешения — микрофон и управление вводом.
Поэтому ядро запускается с `-B` и `PYTHONDONTWRITEBYTECODE=1`.

## Версии

Номер версии один на весь проект и лежит в файле `VERSION` в корне. Оттуда
его берут и сборка (штампует в манифест приложения), и ядро.

Нумерация по [семантическому версионированию](https://semver.org/lang/ru/):
`МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ`. Меняем мажорную — когда ломается совместимость
данных или настроек; минорную — когда добавилась возможность; патч — когда
только починили.

Выпуск версии:

```bash
echo "0.10.0" > VERSION
# записать изменения в CHANGELOG.md, раздел [0.10.0]
git commit -am "Версия 0.10.0"
git tag -a v0.10.0 -m "Версия 0.10.0"
git push && git push --tags
```

Что изменилось между версиями — в [CHANGELOG.md](CHANGELOG.md).

## Работа вдвоём

### Развернуть у себя

```bash
git clone https://github.com/pvaleragpt/-.git slavator
cd slavator
packaging/build_app.sh                    # соберёт Славатор.app
open packaging/dist/Славатор.app          # запустится, дальше кнопка «Установить»
```

Первый запуск предложит развернуть окружение: Python, модели распознавания,
Ollama. Около 6 ГБ и 20–40 минут, один раз.

**Скачивать образ не нужно и не стоит.** Собранное у себя приложение не
помечается карантином, поэтому не будет ни окна «Apple не удалось
подтвердить», ни команды `xattr` в Терминале — эта морока бывает только у
файлов, пришедших из интернета.

Подписывается сборка временной подписью. Единственное следствие: после каждой
пересборки macOS заново спросит доступ к микрофону и к вводу, потому что
считает приложение новым. Если правите только питоновскую часть в `core/`,
пересборка не нужна вовсе — там достаточно запустить `python`.

### Порядок

- `main` — то, что собирается и работает. Прямо в неё не коммитим.
- Ветка на задачу: `feature/диктовка`, `fix/подпись-бандла`.
- Слияние через pull request, чтобы изменение кто-то прочитал.

Правило про комментарии: объяснять **почему**, а не что. Половина неочевидных
решений в этом коде — следы конкретных поломок, и без объяснения следующий
человек их «починит» обратно.

## Чего в репозитории нет и не будет

**Голосовых профилей.** Это биометрия живых людей, и доступ к репозиторию
шире, чем их согласие. `transfer/`, `*.npy` и `speaker_profiles/` закрыты
в `.gitignore` намеренно.

**Записей встреч, стенограмм и словаря терминов** — там рабочее содержимое.

**Моделей, образов и архивов** — гигабайты в git не кладут.
