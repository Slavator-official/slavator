# Славатор

Расшифровка рабочих встреч на macOS и Windows. По умолчанию распознавание и
языковая модель работают на вашем компьютере. Если вручную указать внешний
сервер Ollama, текст для резюме, обычного чата и обработки диктовки отправляется
туда. Чат по памяти встреч и переписки с цитатами остаются локальными.

Что умеет:

- расшифровывает записи встреч и разделяет речь по голосам;
- узнаёт людей по голосу и предлагает имя, вычитанное из разговора;
- на Mac записывает живой звонок: собеседников со звука компьютера, вас с
  микрофона — в один файл;
- на Mac диктует в любое текстовое поле по удержанию правого <kbd>⌥</kbd>;
- собирает резюме, решения и поручения — по кнопке, когда нужно.
- хранит память высказываний: поиск по фразе и смыслу, цитаты с временем,
  история человека и отключаемый граф совместных встреч;
- на Mac отвечает по памяти встреч со ссылками на исходные реплики;
- на Mac проигрывает полную запись с перемоткой и скоростью от 0,5× до 2×.
- на Mac читает PDF и Word в локальном чате;
- обезличивает большие XLSX, CSV/TSV, DOCX, текстовые PDF и TXT/MD офлайн
  и сохраняет отдельную копию того же формата (до 100 МБ, 25 млн символов).

Новый режим обезличивания не использует Ollama или интернет: правила и NER
работают внутри процесса, сетевые подключения запрещены. Сканированные PDF
и PDF с изображениями отклоняются. Из Office-копий удаляются картинки,
вложения и служебные данные; сохраняются текст, таблицы и базовое оформление.
Автоматический поиск не гарантирует нахождение всех данных — проверяйте копию.
Инструкция для передачи: [ОБЕЗЛИЧИВАНИЕ.txt](packaging/ОБЕЗЛИЧИВАНИЕ.txt).

Вкладка «Обезличивание» в боковом меню режима «Чат» готовит копии без персональных данных.
В чате кнопка «Прикрепить файлы…» добавляет один или несколько документов
в контекст вопросов, с цитатами по файлам и страницам.
Автозамены требуют проверки: это не гарантия полного удаления персональных
данных. Поддерживаемые форматы, сканы и экспорт описаны в
[руководстве по документам](docs/ДОКУМЕНТЫ_И_ОБЕЗЛИЧИВАНИЕ.md).

При запуске приложение поднимает уже установленную локальную Ollama без
скачивания моделей. Остановленная служба не считается отсутствующей моделью;
установленный Whisper загружается из локального кэша без повторной проверки сети.

## Как устроено

Две части, связанные через запуск подпроцесса и построчный обмен по stdout.

| Каталог | Что там |
|---|---|
| `app/` | Интерфейс на SwiftUI. Собирается `swiftc` из Command Line Tools, Xcode не нужен |
| `windows/` | Windows-запускатель, PowerShell-установщик и платформенное воспроизведение |
| `core/` | Обработка на Python: распознавание, разделение голосов, документы |
| `packaging/` | Сборка бандла, образа и установщик |
| `docs/` | План развития |
| `legacy/` | Tk-интерфейс: не участвует в macOS-сборке, используется Windows-веткой |

Общие значения настроек и основные цвета обеих платформ находятся в
`core/desktop_contract.json`. Python-клиенты используют `core/app_config.py`,
SwiftUI — `app/Configuration.swift`. Старые поля настроек сохраняются при
обновлении и переключении интерфейса. Приоритет настроек обработки:
явное окружение → выбор в `settings.json` → `config.env` → значения по умолчанию.
Mac-профили в `~/whisper-work` остаются на прежнем месте.

### Объединённая версия — 9 сентября 2026

Изменения объединены в ветке `ios/macbook` репозитория
[Slavator-official/slavator](https://github.com/Slavator-official/slavator/tree/ios/macbook).
Рабочий запуск на настоящих встречах после сборки:
`packaging/dist.noindex/Славатор.app`. Вкладка «Спикеры» содержит поиск и граф;
подробности — [память встреч](docs/ПАМЯТЬ_ВСТРЕЧ.md).
В чате выберите свой профиль в поле «Ваш голос», чтобы вопросы «когда я
говорил» искали именно ваши реплики. Для остальных вопросов выбор не нужен.
В карточке встречи кнопка «Слушать запись» открывает полный проигрыватель.
`packaging/Предпросмотр.command` остаётся отдельным инструментом проверки
дизайна и не нужен для работы с вашими данными.

Для нового CPU-профиля модель распознавания по умолчанию — `small` / int8,
4 потока; существующий явный выбор модели сохраняется. На Mac модель
можно изменить в настройках. Сравнение ресурсов: `docs/benchmarks/`.
Это не означает, что весь продукт уже укладывается в 8 ГБ: отдельная 8B-модель
резюме и постоянно включённая диктовка требуют дополнительной памяти.

Разбор изменений, ограничения и рекомендации: [локальный обзор](docs/ОБЗОР_2026-09-07.md).

Для закрытой ИС подготовлено [сравнение офлайн-архитектур](docs/hardening/hardening.md).
Это предложение, не уже выполненная миграция: текущие установщики требуют
интернет, а общий запрет внешних соединений пока не реализован.

Проверки без загрузки моделей:

```bash
python -m pytest -q core/tests legacy/tk-версия/test_v25_10.py legacy/tk-версия/test_gui_flows_v25_10.py legacy/tk-версия/test_ui_contract_v25_10.py
bash packaging/test_swift.sh  # только macOS
```

Ядро печатает в stdout человеческие строки и машинные `@@PROGRESS@@`;
приложение читает их и рисует ход работы. Диктовка общается с отдельным
постоянным процессом (`core/dictation_worker.py`) построчным JSON в обе
стороны — модель держится в памяти, иначе на каждую фразу уходили бы секунды
на её загрузку.

### Стек

- **faster-whisper** (CTranslate2, без torch) — распознавание речи
- **sherpa-onnx** — разделение голосов, отпечатки голоса, детектор речи
- **Ollama + qwen3:8b** — резюме, определение имён, обработка надиктованного
- **SwiftUI + AppKit** — интерфейс

Текущая установка не требует пользовательских токенов для загрузки используемых
артефактов. Для корпоративной поставки лицензии библиотек и каждого набора весов
нужно проверить отдельно: доступность скачивания не заменяет эту проверку.

## Сборка

### Windows 10/11 x64

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\windows\install.ps1
```

Установщик создаёт локальное Python-окружение, ставит Ollama и добавляет
Славатор в меню «Пуск». Подробности и ограничения — в
[`windows/README.md`](windows/README.md).

### macOS 14.2+

```bash
packaging/build_app.sh          # собрать Славатор.app
packaging/make_dmg.sh           # лёгкий образ (~2 МБ)
packaging/make_dmg.sh --full    # полный (~5 ГБ): Ollama и модель внутри
```

Требуется macOS 14.2 и новее на Apple Silicon. Command Line Tools обязательны,
полный Xcode — нет.

### Проверка после каждой сборки

Две вещи ломались молча и стоили дня работы, поэтому проверяются всегда:

```bash
otool -L packaging/dist.noindex/Славатор.app/Contents/MacOS/slavator | grep -c SwiftUICore   # 0
codesign --verify packaging/dist.noindex/Славатор.app                                        # valid
```

`SwiftUICore` — фреймворк из macOS 15. Если линковщик его пропишет,
приложение не запустится на macOS 14 вовсе: падение при старте, без окна.
Тянут его `.fixedSize()`, свои раскладки на протоколе `Layout` и `.tag()`
в `Picker` — эти три вещи в коде не использовать.

Подпись ломается, если Python успевает записать `__pycache__` внутрь бандла.
Вместе с подписью слетают выданные разрешения — микрофон и управление вводом.
Поэтому ядро запускается с `-B` и `PYTHONDONTWRITEBYTECODE=1`.

## Версии

Номер версии один на весь проект и лежит в файле `VERSION` в корне. Оттуда
его берут и сборка (штампует в манифест приложения), и ядро.

Нумерация по [семантическому версионированию](https://semver.org/lang/ru/):
`МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ`. Меняем мажорную — когда ломается совместимость
данных или настроек; минорную — когда добавилась возможность; патч — когда
только починили.

Выпуск версии:

```bash
echo "0.10.0" > VERSION
# записать изменения в CHANGELOG.md, раздел [0.10.0]
git commit -am "Версия 0.10.0"
git tag -a v0.10.0 -m "Версия 0.10.0"
git push && git push --tags
```

Что изменилось между версиями — в [CHANGELOG.md](CHANGELOG.md).

## Работа вдвоём

### Развернуть у себя

```bash
git clone https://github.com/pvaleragpt/-.git slavator
cd slavator
packaging/build_app.sh                    # соберёт Славатор.app
open packaging/dist.noindex/Славатор.app          # запустится, дальше кнопка «Установить»
```

Первый запуск предложит развернуть окружение: Python, модели распознавания,
Ollama. Около 6 ГБ и 20–40 минут, один раз.

**Скачивать образ не нужно и не стоит.** Собранное у себя приложение не
помечается карантином, поэтому не будет ни окна «Apple не удалось
подтвердить», ни команды `xattr` в Терминале — эта морока бывает только у
файлов, пришедших из интернета.

Подписывается сборка временной подписью. Единственное следствие: после каждой
пересборки macOS заново спросит доступ к микрофону и к вводу, потому что
считает приложение новым. Если правите только питоновскую часть в `core/`,
пересборка не нужна вовсе — там достаточно запустить `python`.

### Порядок

- `ios/macbook` — текущая основная ветка; также существуют `windows` и `ubuntu`.
- Название `ios/macbook` не означает поддержку iPhone: приложение на SwiftUI здесь собирается для macOS.
- Ветка на задачу: `feature/диктовка`, `fix/подпись-бандла`.
- Слияние через pull request, чтобы изменение кто-то прочитал.

Правило про комментарии: объяснять **почему**, а не что. Половина неочевидных
решений в этом коде — следы конкретных поломок, и без объяснения следующий
человек их «починит» обратно.

## Чего в репозитории нет и не будет

**Голосовых профилей.** Это биометрия живых людей, и доступ к репозиторию
шире, чем их согласие. `transfer/`, `*.npy` и `speaker_profiles/` закрыты
в `.gitignore` намеренно.

**Записей встреч, стенограмм и словаря терминов** — там рабочее содержимое.

**Моделей, образов и архивов** — гигабайты в git не кладут.
