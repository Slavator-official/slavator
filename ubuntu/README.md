# Славатор для Ubuntu

> Статус: заготовка на будущее. Это не готовый релиз.

Ветка `ubuntu` выделена заранее, чтобы будущий Linux-порт не
смешивался с релизами `ios/macbook` и `windows`.

## Что можно переиспользовать

- Python-ядро из `core/`;
- faster-whisper, sherpa-onnx, PyAV и Ollama;
- Tk-интерфейс как основу первого прототипа;
- форматы профилей, стенограмм и резюме без изменения схемы.

## Что нужно сделать

1. Проверить полную установку зависимостей на Ubuntu 24.04 LTS x86_64.
2. Перенести пути данных в XDG-каталоги.
3. Добавить захват звука через PipeWire/PulseAudio.
4. Продумать глобальную диктовку отдельно для Wayland и X11.
5. Собрать пакет `.deb` или AppImage без требования ручной настройки Python.
6. Прогнать микрофон, системный звук и часовую запись на чистой VM.

## Правило ветки

Общие исправления Python-ядра переносятся между тремя ветками.
Платформенные установщики, UI и аудиозахват остаются только в своей
платформенной ветке.
