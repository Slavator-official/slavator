# Локальное объединение перед проверкой

Коммит и публикация не выполнялись. Исходная ветка и remote сохранены.
Источник коллеги: Slavator-official/slavator, ветка ios/macbook,
коммит 6e21b343a4b636ab94526410d3109ab4fab5403d; общий предок 4f1cbf7.

## Перенесено в Mac-приложение

- Назначение клавиш диктовки и обработки, включая fn и комбинации модификаторов.
- Сохранение речи, записанной во время распознавания предыдущей фразы; запас настоящей тишины на границе.
- Ввод текста без унаследованных модификаторов удерживаемой клавиши.
- Обновлённые инструкции локальной модели для чистки, структуры и сокращения диктовки.
- Управляемый значок в меню, запись из меню и виджет на рабочем столе.
- Предложение записать звонок при использовании микрофона другим приложением.
  По умолчанию выключено, запись начинается только после действия пользователя.
- Единая диагностика установленных библиотек и моделей, восстановление после
  отдельного подтверждения загрузок из интернета.
- Исправление чтения строк Core Audio и применение темы к нативным окнам.

## Сохранено и добавлено поверх объединения

- Общие настройки Python/Swift с сохранением неизвестных полей, надёжная отмена процессов.
- Память встреч, подтверждённые профили, цитаты, контекст и прослушивание.
- Корзина с восстановлением всех версий встречи; исключение архивных дублей.
- Фильтрация самостоятельных служебных обрывков без удаления исходного текста.
- Переключатель «Строить граф встреч»: при выключении связи не вычисляются,
  поиск по текстам остаётся доступен. Настройка работает и в Tk-интерфейсе.
- Mac-чат по памяти встреч с выбором «Это я», источниками и отменой.
  Вопрос «я говорил» фильтруется по явно выбранному профилю, не по догадке модели.

## Осознанные отличия от ветки коллеги

- Не перенесены удаления Windows-файлов из Mac-ветки. Наша рабочая Tk-версия сохранена.
  Отдельный новый Edge-интерфейс из windows@efcd887 не заменяет её в этой сборке:
  это самостоятельный интерфейс, ещё не объединённый с нашей памятью и корзиной.
  Ubuntu-ветка содержит общий код диагностики и заготовку CI, не готовое Linux-приложение.
- При изменении уже напечатанного начала фразы не дописываем весь изменённый хвост:
  это могло дублировать текст в чужом редакторе. Сохранено правило не переписывать ввод.
- Прогрев языковой модели — только для обработки диктовки, не при запуске приложения;
  удержание по умолчанию сокращено с 30 минут до одной для экономии RAM.
- Проверка готовности не запускает Ollama и не загружает модели.
  Восстановление требует явного --allow-download; удалённый адрес для него запрещён.
- Тег модели сопоставляется точно; неполный кэш Whisper и отсутствие библиотек
  не считаются готовностью.
- Чат по памяти всегда использует 127.0.0.1, без системных прокси и перенаправлений.
  Даже после выключения режима памяти переписка с цитатами остаётся локальной.
- Граф — совместное участие во встречах, а не выдуманные отношения людей.
  Ответ модели — интерпретация найденных фрагментов, которую надо проверить по источникам.

## Проверка и границы

Python-проверки включают реальную локальную Ollama; Swift — сохранение старых настроек,
отмену процессов, корзину, обновление имён и изоляцию ответов разных переписок.
Реальный запрос по сохранённым встречам вернул цитаты выбранного профиля.
Работа нового интерфейса и аудио на Windows/Ubuntu в этой среде не проверялась.
Производительность чата с qwen3:8b на машине с 8 ГБ не измерена: модель тяжёлая,
и выбранная пользователем модель не заменялась автоматически.
Архитектурная миграция из документа hardening остаётся отдельным согласованием.
