# Славатор для Windows

Тот же продукт, что на маке: те же цвета, та же раскладка, то же ядро
обработки. Отличается только оболочка окна — SwiftUI на Windows не бывает.

## Установка

```powershell
git clone git@github.com:pvaleragpt/-.git slavator
cd slavator
powershell -ExecutionPolicy Bypass -File windows\install.ps1
```

Установщик найдёт или поставит Python 3.12, поднимет окружение в
`%APPDATA%\Славатор`, положит файлы в `%LOCALAPPDATA%\Programs\Славатор`,
поставит Ollama с моделью и создаст ярлык в меню «Пуск».

Около 6 ГБ загрузки и 20–40 минут, один раз. Если Ollama уже стоит, а модель
скачана, эти шаги пропускаются.

Ключи: `-SkipOllama` — без языковой модели (резюме и чат работать не будут),
`-NoLaunch` — не открывать окно после установки.

## Запуск

Ярлык «Славатор» в меню «Пуск». Или вручную:

```powershell
powershell -ExecutionPolicy Bypass -File windows\run.ps1
```

## Как устроено

| Файл | Что делает |
|---|---|
| `slavator.py` | Окно и мост: запускает ядро подпроцессом, разбирает `@@PROGRESS@@`, отдаёт данные интерфейсу |
| `ui/index.html` | Весь интерфейс. Цвета перенесены из `app/Theme.swift` — один в один с маком |
| `install.ps1` | Установка окружения, Ollama, ярлыка |
| `run.ps1` | Запуск установленной копии |
| `test_bridge.py` | Проверка моста: то, что нельзя поймать компиляцией |

Окно рисует движок Edge (WebView2), встроенный в Windows. Отдельного браузера
и отдельного установщика для него не нужно — установщик только проверяет, что
он на месте.

## Живая запись и диктовка

**Запись звонка.** Звук компьютера берётся петлёй WASAPI — Windows позволяет
слушать то, что уходит в динамики, как обычный вход. Виртуальные устройства
вроде VB-Cable не нужны. Микрофон пишется отдельной дорожкой: сводить их
нельзя, иначе собеседник попадёт в запись дважды и распознавание развалится.
Обе дорожки держатся общих часов — недостача добивается тишиной, иначе
нулевая секунда у двух файлов означала бы разные моменты.

**Диктовка.** Держите правый <kbd>Alt</kbd> — текст печатается туда, где стоит
курсор. С <kbd>Shift</kbd> сказанное сначала причёсывается языковой моделью.
Клавиша ловится низкоуровневым хуком, текст печатается через `SendInput` с
флагом `KEYEVENTF_UNICODE` — так кириллица не зависит от раскладки. Прав
администратора не нужно.

Напечатанное **никогда не переписывается**: модель уточняет только хвост
последней фразы, а пауза закрывает фразу целиком. Иначе пришлось бы слать
Backspace вслепую в чужой редактор.

> **Это написано, но не проверено на живой машине.** Разработка идёт на маке,
> а звук и синтез ввода на Windows проверить оттуда нечем: у сборочной машины
> нет ни звуковых устройств, ни рабочего стола. Проверено то, что поддаётся:
> модули грузятся, размер структуры для `SendInput` верный, перечисление
> устройств не роняет процесс, склейка устоявшейся части считается правильно.
> Первому, кто запустит на Windows, стоит начать именно с этих двух функций.

## Если не открывается

Ярлык запускает `pythonw.exe`, у которого нет консоли: любая ошибка при
старте уходит в никуда, и программа просто не появляется. Поэтому:

```powershell
powershell -ExecutionPolicy Bypass -File windows\diagnose.ps1
```

Скрипт проходит по всей цепочке — окружение, pywebview, pythonnet, движок
Edge, библиотеки обработки, Ollama — и показывает, где обрыв. В конце
выводит последние строки журнала запусков.

Журнал лежит здесь и пишется при каждом старте:

```
%APPDATA%\Славатор\logs\app.log
```

Если что-то ломается уже в окне, интерфейс не молчит: вместо пустоты
показывается сообщение с причиной — его можно скопировать целиком.

## Проверка

```powershell
python -m pytest windows\test_bridge.py
```

Полная проверка идёт на сборочной машине с настоящей Windows: синтаксис
PowerShell, установщик целиком, запуск ядра. Смотреть во вкладке Actions.
