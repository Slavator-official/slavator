# Славатор для Windows

Целевая система: Windows 10/11 x64. Распознавание, разделение
голосов, голосовые профили и документы остаются локальными.

## Установка

Откройте PowerShell в корне репозитория:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\windows\install.ps1
```

Скрипт ставит Python 3.12 в профиль пользователя, создаёт изолированное
окружение, копирует приложение в `%LOCALAPPDATA%\Programs\Славатор` и добавляет
ярлык в «Пуск». Ollama и `qwen3:8b` нужны только для резюме.

Без 5-ГБ языковой модели:

```powershell
.\windows\install.ps1 -SkipOllama
```

## Запуск из исходников

```powershell
.\windows\run.ps1
```

## Ограничения первой Windows-ветки

- Обработка готовых аудио/видео и запись с микрофона работают.
- Захват системного звука и диктовка в любое поле пока остаются macOS-функциями.
- На Windows повторный щелчок по WAV останавливает звук; продолжение с той же позиции нет.
